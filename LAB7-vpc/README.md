## **Цель:**
# **Настроить отказоустойчивое подключение клиентов с использованием технологии VPC.**

### **План работ:**
1. Подключить коммутатор доступа (sw-access) двумя линками к leaf1 и lef2. Хост pc5 подключит в коммутатор доступа.
2. Настроить агрегированный канал (LACP -PO1) на стороне коммутатора доступа.
3. Настроить VPC домен на leaf1 и leaf2/ peer-link (eth1/3,eth1/4)/ keepalive link (mgmt inteface), а также агрегированный канал (LACP -PO6) в сторону коммутатора доступа.
4. Диагностика результатов: vpc собралсся, статус vpc -консистентный, PO6 -поднят/ поданы нужные влан, есть связанность хостов pc5 и pc3.
5. Фиксация результатов.

## **Цель:**
# **Настроить Overlay на основе VxLAN EVPN для L2 связанности между клиентами.**

### **План работ:**
1. Настроите BGP peering между Leaf и Spine в AF l2vpn evpn
2. Проверить связанность между клиентами PC1, PC2, PC3.
3. Диагностика соседства/ таблицы маршрутизации в vpnl2/ доступность хостов, подключенных к разным лифам.
4. Фиксация результатов.

## **Цель:**
# **Реализовать передачу суммарных префиксов через EVPN route-type 5**

### **План работ:**
1. Подключить коммутатор доступа (внешнее устройство: sw-usr) двумя линками к leaf1 и lef2 (vpc po6).
2. Разместить двух "клиентов" в разных VRF (OTUS, OTUS2) в рамках одной фабрики.
3. Настроить маршрутизацию между клиентами разных vrf через внешнее устройство sw-usr.
4. Диагностика результатов: маршруты из обоих vrf получены по bgp на внешнем устройстве sw-usr от граничных leaf1/leaf2; средствами sw-usr произведен leaking маршрутов, т.е. маршруты из vrf-OTUS появились в vrf-OTUS2 (и на оборот) на коммутаторах фабрики leaf1,leaf2,leaf3 .
5. Фиксация результатов.

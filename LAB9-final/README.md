# **Реализовать взаимодействие сегментов, раположенных в разных подах**

### **План работ:**
1. Собрать два пода. Объединить поды spine-ми, согласвно схемы.
2. Разместить двух "клиентов" в разных сегментах, согласно таблице. Проверить доступность хостов.
3. Диагностика результатов: маршруты из обоих vrf получены по bgp на внешнем устройстве sw-usr от граничных leaf1/leaf2; средствами sw-usr произведен leaking маршрутов, т.е. маршруты из vrf-OTUS появились в vrf-OTUS2 (и на оборот) на коммутаторах фабрики leaf1,leaf2,leaf3 .
4. Фиксация результатов.

## **Цель: Реализовать дизайн Multi-Pod**
# **Обеспечить взаимодействие сегментов, раположенных в разных подах**

### **План работ:**
1. Собрать два пода. Объединить поды линками на spine-ах, согласно схемы.
2. Разместить "клиентов" в разных сегментах, согласно таблице. (10 влан растянут на оба пода, anycast gw на обоих подах / 20 влан L3 живет только в POD1, L2vni -POD2 / 50 влан развернут только в POD2, POD1 знает о нем по type5). 
3. Диагностика результатов: соседство по nve лифов, таблица маршрутизации, доступность хостов.
4. Фиксация результатов.
